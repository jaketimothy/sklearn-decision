# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the repository (issues, pull requests, discussions and reviews) and wherever you represent the project.

In short:

- **Be respectful and constructive.** Critique code and results, not people.
- **Welcome newcomers.** Questions are fine, and so is being wrong.
- **No harassment,** personal attacks, discriminatory language or unwelcome attention, in public or in private.
- **Respect privacy.** Don't publish others' private information, including data they shared to reproduce a bug.

## Reporting

Report conduct concerns privately to the maintainer, [@jaketimothy](https://github.com/jaketimothy), through the [private reporting form](https://github.com/jaketimothy/sklearn-decision/security/advisories/new). Start the title with "Conduct:". Reports are kept confidential.

The maintainer will review each report and respond as the Contributor Covenant's enforcement guidelines describe, from a warning up to a ban from the project.
